## Overview

This repository serves as a collection of my independent research, hands-on laboratories, technical exercises, infrastructure case studies, and professional development activities related to system administration.

As a Rochester Institute of Technology graduate with an academic focus in Civil Engineering Technology and Computer Engineering Technology, I am developing my technical expertise in IT infrastructure, network engineering, and cybersecurity.

The purpose of this repository is to demonstrate my understanding of system administration concepts, practical troubleshooting abilities, technical decision-making, and ability to document technical processes in a professional environment.

## Repository Objectives

- Develop a strong foundation in system administration.
- Gain practical experience managing Linux and Windows environments.
- Understand enterprise infrastructure and deployment models.
- Develop structured troubleshooting methodologies.
- Explore virtualization and cloud computing technologies.
- Understand system security and access management.
- Develop scripting and automation skills.
- Apply theoretical knowledge to realistic business scenarios.
- Maintain professional technical documentation.
